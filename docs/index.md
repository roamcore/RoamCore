# RoamCore Docs

RoamCore is Home Assistant tuned for van life: clear dashboards, sensible defaults, and a catalog of things you can connect as your build evolves.

## Start here

- **New user?** Begin with the installer and a quick walkthrough.
  - [Install RoamCore](howto/homeassistant-installer.md){ .rc-cta }
- **Looking for ideas?** Browse the catalog by category (Power, Map, Networking, Safety…).
  - [Browse the Integrations Catalog](catalog/index.md){ .rc-cta }

## Support tiers

RoamCore uses simple support tiers throughout this catalog:

- <span class="rc-tier a">A</span> RoamCore native (we own it; supported)
- <span class="rc-tier b">B</span> Home Assistant supported (existing integration; setup required)
- <span class="rc-tier c">C</span> Custom/manual (no support; inspiration/potential)

## Philosophy

This site intentionally links out to the best upstream docs (Home Assistant, vendors, and community projects) so you don’t have to maintain duplicate instructions.
