# Support & troubleshooting

## First things to try

- **Restart Home Assistant** after installing or provisioning RoamCore assets.
- If you installed via **HACS** and only the integration appears (but dashboards/packages are missing), run the provisioning service:
  - Service: `roamcore.provision_assets`

## Export a support bundle

If you need help debugging, export a bundle you can attach to a GitHub issue:

- How-to: `docs/howto/support-bundle.md`
