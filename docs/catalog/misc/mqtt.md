# MQTT

MQTT — RoamCore catalog entry.

## What you need

- Nothing extra — uses what's already in the van.

## Install

- Add this repo as a **HACS custom repository** (Category: *Integration*), then install **mqtt**.
- Restart Home Assistant.
- Done — the tiles appear under the relevant section in the dashboard.

## What it shows on your dashboard

- A MQTT tile that updates automatically.
