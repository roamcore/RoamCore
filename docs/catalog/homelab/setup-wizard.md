# Setup Wizard (RoamCore onboarding)

**Support tier:** A (RoamCore native)

## What this is
RoamCore includes a setup/onboarding wizard that guides users through the minimum configuration needed to make the dashboard feel “alive”.

## Why it’s useful in a van
- Faster first-time setup
- Fewer “blank/unknown” tiles
- Clear checklist for what to connect next

## Extra hardware required
- None (wizard adapts based on what you have connected)

## Install / best next step
- HA package: `homeassistant/packages/roamcore_setup_wizard.yaml`
- UI lives in the RoamCore frontend (`homeassistant/www/roamcore/roamcore-pages.js`)
