- "If temp drops below 0°F tonight, pre-heat engine + floor at 5 AM."
- "If rain forecast for the next 6 hours, close roof fan."
- "If severe-weather alert, send push notification."

All of these ride on the standard HA weather integration — RoamCore's
recipe layer makes them one-click to install.
