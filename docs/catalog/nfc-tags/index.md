# NFC Tags

Cheap NFC tags you can stick anywhere — tap your phone to run a scene.

The full NFC-tag guide lives in the Connections section:

- **[Connection: NFC tags](../../connections/nfc-tags/docs/recipe.md)** — vendor-neutral `tag_id → scene` mapping recipe over the upstream Home Assistant `tag` integration, the HA Companion app, and the HACS `nfcpy` integration. Example scenes: Lights off, Bedtime, Leave camp. **Experimental** — it builds but hasn't been integration-tested yet.

See the connection page for how to register a tag and bind it to a scene.
