# Alternator charge control

Wakespeed / Balmar / Sterling / Renogy / REDARC / EP-Power / ARCO / OEM smart alternator regulators.

## What you need

- Zigbee smoke / CO detector ($30–$80 each)

## Install

- Click **Add to my van** in the RoamCore dashboard, **or** run `bash <(curl -sL https://raw.githubusercontent.com/roamcore/RoamCore/main/install.sh) --feature alternator-charge-control`.
- Restart Home Assistant.
- Done — the tiles appear under the relevant section in the dashboard.

## What it shows on your dashboard

- A Alternator charge control tile that updates automatically.
