# Heated floors + engine pre-heat (cold weather comfort)

Bring cold-weather comfort controls into one place: heated floors, engine pre-heat, and other “warm-up” routines that make winter van life less punishing.

## How to install
- A controllable heated floor system (relay/thermostat/integration)
- Optional: an engine pre-heat solution (hardware dependent)
- Temperature sensors (interior/ambient)

## How it works
- Provide a single “Warm up” scene (HVAC + power-safe checks)
- Surface temperatures and clear state (“Heating”, “Maintaining”, “Off”)

## Common automations (ideas)
- Use electric heating when on shore power
- Pre-warm the van when you arrive back (presence)
- Disable high loads if battery SOC is low
