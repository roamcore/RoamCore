# Community

This folder is the **Community** tag in the RoamCore catalog.

## Overview
The RoamCore community shares setups, dashboards, and helper recipes. The Labs subsystem (Wave 2 #32) is the contract layer that makes the shareable setup pipeline work: privacy-by-default, no remote upload, no third-party HTTP. The owner bundles the active setup as a local tar.gz and shares it via any channel they trust.
