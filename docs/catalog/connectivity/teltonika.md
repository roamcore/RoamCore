# Teltonika

Teltonika RUT-series LTE/5G routers are rugged, configurable mobile-internet gateways widely used in van life.

## What you need

- Nothing extra — uses what's already in the van.

## Install

- Follow the **Setup** steps in the recipe — this is a manual install that wires a few entities together.
- Restart Home Assistant.
- Done — the tiles appear under the relevant section in the dashboard.

## What it shows on your dashboard

- Teltonika reachable
- Teltonika wan state
- Teltonika signal pct
- Teltonika lte mode
- Teltonika carrier
- Teltonika data used gb
- Teltonika uptime hours
- Teltonika public ip
- Teltonika data reset
- Teltonika reboot now
- Teltonika refresh signals
