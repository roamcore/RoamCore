# Traccar Proxy add-on

**Support tier:** A (RoamCore native)

## What this is
A Home Assistant add-on that proxies Traccar endpoints to make setup and local integration more reliable.

## Why it’s useful in a van
- Stable tracking integration
- Fewer moving parts to manage

## Extra hardware required
- Traccar client/tracker

## Install / best next step
- Add-on: `homeassistant/addons/roamcore-traccar-proxy`
- Component: `homeassistant/custom_components/roamcore_traccar_proxy`
