# Trip Local (local GPX / local trip tools)

## What it does
RoamCore includes a “Trip Local” path for working with local trip data/tools inside Home Assistant.

## Why it’s useful in a van
- Useful when you don’t want to depend on a cloud service
- Helps keep trip history and exports under your control

## How to install
- None

- HA package: `homeassistant/packages/roamcore_trip_local.yaml`
- Tooling lives under: `homeassistant/tools/trip_local/`
