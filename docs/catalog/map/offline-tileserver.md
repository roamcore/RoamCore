# Offline maps / Tile server (PMTiles)

**Support tier:** A (RoamCore native)

## What this is
RoamCore includes a local tile server path so maps can render reliably without depending on third-party map providers.

## Why it’s useful in a van
- Maps still work when internet is poor
- Faster, more predictable map rendering

## Extra hardware required
- None beyond your Home Assistant host storage (more storage helps for larger tilesets)

## Install / best next step
- RoamCore tile server component: `homeassistant/custom_components/roamcore_tileserver`
- Add-on: `homeassistant/addons/roamcore-tileserver`
