# Trip Wrapped (route recap report)

## What it does
Trip Wrapped generates a shareable, beautiful HTML report of a trip/route.

## Why it’s useful in a van
- A fun end-of-trip recap
- Easy to share with friends/family

## How to install
- Typically none beyond your location history source (often Traccar)

- See existing notes in `homeassistant/tools/trip_wrapped/`
- RoamCore also exposes `/local/roamcore/trip_wrapped/latest.html` when configured
- HA package: `homeassistant/packages/roamcore_trip_wrapped.yaml`
