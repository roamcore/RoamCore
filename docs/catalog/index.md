## Tier legend

Each connection card shows who built it honestly:

- **RoamCore Certified** — RoamCore builds and maintains this end-to-end.
- **Community Verified** — A member of the community tested this on a real van.
- **Experimental** — It builds but hasn't been integration-tested yet.
