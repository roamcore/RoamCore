# Resources (inspiration + community)

This is a growing list of projects, communities, and media that RoamCore users often find useful when upgrading their van/off-grid system.

If you join any of these communities, feel free to mention you came from **RoamCore** — it helps the ecosystem grow.

> Note: this list will evolve. If a link dies or a community changes, open an issue or PR.

---

## Support / troubleshooting

- `docs/resources/support.md` (support entry point)
- `docs/howto/support-bundle.md` (export a RoamCore support bundle)

## Core platforms

- https://www.home-assistant.io/ (Home Assistant — the foundation RoamCore builds on)
- https://esphome.io/ (ESPHome — easiest path to add sensors like tank levels, temps, switches)
- https://mqtt.org/ (MQTT — common messaging layer for off-grid/IoT systems)

## Power (Victron / solar / batteries)

- https://www.victronenergy.com/live/ (Victron documentation hub — product + Venus OS docs)
- https://github.com/victronenergy/dbus-flashmq/blob/master/README.md (Victron dbus-flashmq MQTT docs — authoritative topic semantics)

## Connectivity (Starlink / LTE / Wi‑Fi / routing)

- https://tailscale.com/ (Tailscale — simple secure remote access to your van network)
- https://openwrt.org/ (OpenWrt — powerful router OS; useful for multi-WAN + Wi‑Fi client mode)

## Maps / trip logging / navigation

- https://www.traccar.org/ (Traccar — self-hosted GPS tracking; used by RoamCore Trip Wrapped)

## Community / inspiration

- https://www.reddit.com/r/vandwellers/ (r/vandwellers — broad vanlife community + build inspiration)
- https://www.reddit.com/r/VanLife/ (r/VanLife — photos + setups + gear discussions)
- https://www.reddit.com/r/homeassistant/ (r/homeassistant — help + inspiration for HA-based systems)

## Video / learning

- https://www.youtube.com/@homeassistant (Home Assistant YouTube — official updates + tutorials)
